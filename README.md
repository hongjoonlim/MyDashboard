# 나의 오늘 대시보드

날씨, 세계 시간, USD/KRW 및 EUR/KRW 환율을 한 화면에서 확인하는 개인용 정적 웹 대시보드입니다.

## 실행

`index.html` 파일을 브라우저에서 열면 됩니다. 별도의 설치나 빌드 과정은 필요하지 않습니다.

## 데이터 출처

- 날씨: Open-Meteo
- 환율: Frankfurter (ECB 기준환율)

기본 날씨 위치는 비엔나이며, 오늘의 날씨 카드 안의 **위치 변경** 버튼으로 도시를 바꿀 수 있습니다. 선택한 위치는 브라우저에 저장됩니다.

## 연비 환산

**Tools** 탭의 자동차 연비 환산에 L/100km 값을 입력하면 `100 ÷ 입력값`으로 km/L를 즉시 계산합니다. 예: 8 L/100km → 12.50 km/L. 자주 쓰는 값과 현재 입력값을 환산표에서 비교할 수 있으며, 빈 값이나 0 이하의 입력에는 안내가 표시됩니다.
